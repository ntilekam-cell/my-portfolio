# Mzuvukile Ntileka — Personal Website & Developer Portfolio

Welcome to the source code for my personal website and developer portfolio, built from scratch as part of my self-taught coding journey and **BSc in Computing** studies.

🌐 **Live Website:** [https://github.io](https://github.io)

---

## 🚀 Features & Pages

* **Home (`index.html`):** Personal landing page featuring responsive Flexbox layouts, custom audio integration, and interactive jQuery navigation.
* **Portfolio (`Untitled1.html`):** My background story, academic journey in Computing, and a showcase of my software development work.
* **My Jumper Game (`game.html` & `game.js`):** An interactive HTML5 Canvas arcade game built with vanilla JavaScript featuring gravity physics, bouncy ceiling/floor walls, collision detection, and score tracking.

---

## 💻 Featured Software Projects

* **[Student Gradebook Benchmark (`student-gradebook-cpp`)](https://github.com):** A C++ console application utilizing custom class design and operator overloading (`>>`, `<<`, `>=`) to read and filter student records against target benchmarks.

---

## 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3 (Flexbox, responsive design, custom gradients), JavaScript (ES6+), jQuery
* **Other Languages in My Stack:** C++ and Python (currently building and uploading new console applications and scripts to my GitHub profile)
* **Hosting:** GitHub Pages
